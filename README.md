# Chonk Patrol 🐈

A calm little browser game. You're looking out a cozy window, and cats wander by — on the fence, in the trees, near the house. Click them before they slip away.

No timer, no losing, no pressure. Just a peaceful "notice the cats" experience.

For Arina 🤍

## How to play

Open `index.html` in any browser. That's it — no install, no build step, no dependencies.

- Cats appear at random spots and stay for a few seconds
- Click (or tap) a cat to spot it — each one gives a little reaction
- Keep an eye out for glowing special cats; they linger longer
- Small surprises at 10, 25, and 50 cats spotted
- After 75, the cats head home for a rest — but you can always keep watching the window

## Files

| File | What it does |
|------|--------------|
| `index.html` | The page: window scene, score counter, ending screen |
| `style.css` | The cozy look: sky, clouds, windowsill, animations |
| `script.js` | The game: cat spawning, clicking, score, milestones |

## Hosting it online

The game is a static page, so GitHub Pages hosts it for free:

1. Create a new GitHub repository and upload these files
2. Go to **Settings → Pages** and set the source to the `main` branch
3. GitHub gives you a link you can send to anyone
